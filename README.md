# Portfolio

A small corner of the internet for my work, projects, and the occasional questionable technical decision.

Built as a single-page portfolio with a focus on keeping things simple, fast, and reasonably good-looking.

## Stack

* [Astro](https://astro.build/)
* [Tailwind CSS](https://tailwindcss.com/)
* TypeScript
* [Cloudflare Workers](https://workers.cloudflare.com/)

## Development

```bash
pnpm install
pnpm dev
```

## Build & Deployment

```bash
pnpm exec wrangler types
pnpm build
pnpm exec wrangler deploy
```
